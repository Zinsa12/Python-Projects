
# Python Programming Projects

## Overview

This repository contains multiple Python programs developed to demonstrate fundamental and advanced Python programming concepts. These projects cover user input handling, pattern generation, data analysis, student management, and employee management systems using Object-Oriented Programming (OOP).

---

## Projects Included

### 1. Personal Data Collector

A program that collects personal information from the user and displays the entered data along with data types and calculated birth year.

**Concepts Used:**

* Variables and Data Types
* User Input and Output
* Type Conversion
* Formatted Strings

---

### 2. Pattern Generator and Number Analyzer

A menu-driven application that generates star patterns and analyzes numbers within a specified range.

**Features:**

* Generate star patterns
* Check Even/Odd numbers
* Calculate sum of a range

**Concepts Used:**

* Loops
* Conditional Statements
* Match-Case
* Nested Loops

---

### 3. Student Data Organizer

A system for managing student records including student details, subjects, updates, and deletions.

**Features:**

* Add Student
* Display Students
* Update Student Information
* Delete Student
* Display Unique Subjects

**Concepts Used:**

* Lists
* Dictionaries
* Sets
* Tuples
* CRUD Operations

---

### 4. Data Analyzer and Transformer

A data processing application that performs various operations on datasets.

**Features:**

* Input Dataset
* Data Summary
* Factorial Calculation
* Data Filtering
* Data Sorting
* Dataset Statistics

**Concepts Used:**

* Functions
* Recursion
* Lambda Functions
* Built-in Functions
* Return Multiple Values

---

### 5. Employee Management System

An Object-Oriented Programming based application for managing employees, managers, and developers.

**Features:**

* Add Person
* Add Employee
* Add Manager
* Add Developer
* Display Records

**OOP Concepts Used:**

* Classes and Objects
* Inheritance
* Encapsulation
* Method Overriding
* Constructors
* Destructors

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Run the desired Python file:

```bash
python filename.py
```

Example:

```bash
python employee_management_system.py
```
